# Guardia Orbitale

Sparatutto arcade a schermo fisso che gira nel browser. Un solo file (`index.html`), nessuna dipendenza.

## Come si gioca
- Frecce sinistra/destra (o A/D) per muoversi, Spazio per sparare, P per la pausa
- Su telefono: trascina il dito, la nave spara da sola
- Chi colpisci in picchiata vale doppio, la cometa in alto dà punti bonus
- Power-up: S (colpo triplo), R (fuoco rapido), + (scudo)

## Come pubblicarlo
Apri `index.html` in locale, oppure attiva GitHub Pages sul branch principale.
